Code Resources

1. agent_system.py

Multi-Agent Swarm Implementation

A Python-based multi-agent system where autonomous AI agents collaborate to detect and fix data anomalies. It contains:

  • AnomalyDetectorAgent — Scans data rows against schema rules to find logical contradictions (e.g., a 7-year-old with a PhD)
  • MemoryEngineAgent — Stores and retrieves learned organizational rules, continuously expanding knowledge
  • HITLAgent — Handles Human-in-the-Loop decisions: accept fixes or override-and-learn new rules
  • AgentSwarm — Orchestrator that coordinates all agents end-to-end through the detection → flagging → remediation pipeline

Uses OpenAI GPT-4o-mini for LLM-powered thinking, Pydantic for data validation.

2. data ingestion.js

Express Backend API

A Node.js/Express server that provides REST API endpoints for the React dashboard. It:

  • GET /api/anomalies — Fetches pending anomalies flagged by the multi-agent swarm
  • POST /api/remediation — Handles HITL decisions (accept fix or override-and-learn)
  • Organizational Memory — Acts as a vector database (Pinecone/Weaviate) storing learned rules

Uses CORS for cross-origin support, JSON middleware for request parsing. Runs on PORT 3001.

3. create_ppt.py

PowerPoint Generator Script

A Python script using the python-pptx library to automatically generate presentation slides. It creates a 10-slide deck covering:

  • Title slide & System Architecture overview
  • Data Pipeline Flow & Anomaly Examples
  • API Endpoints & Organizational Memory
  • Key Features & Technology Stack
  • Agent Code Examples & Summary

Outputs AI_Data_Quality_Analyzer.pptx with custom styling (Navy/Blue/Teal theme).
